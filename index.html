How Skills Are Calculated

1. Game Skill Weights
Each game has skill weights (0-10) set via "Edit Skills" in the Games tab. These define what skills the game tests.

2. Dominance Per Game
For each game, your "dominance" is calculated as your wins divided by total wins in that game. If you have 4 wins and others have 6, your dominance is 40%.

3. Skill Points Earned
You earn skill points based on dominance multiplied by the game's skill weights. Dominate a luck-heavy game? You get more L points.

4. Average Across Games
Your skill scores are averaged across all games you've won. This measures how good you are at the games you play, not how many games you've played.

5. Chart Scaling
All player charts use the same scale based on the highest individual skill value. This allows direct visual comparison between players.
